The Market & The Problem

Why Peer-to-Peer Skill Exchange?

⚠️

Current EdTech Limitations

  • ✕ Exorbitant Costs: Private tutors and bootcamps charge \$50-\$150/hour, creating heavy financial barriers for students and professionals.
  • ✕ Passive Learning: Pre-recorded video courses suffer from abysmal <10% completion rates due to lack of interactive feedback.
  • ✕ Untapped Expertise: Millions of individuals possess valuable skills (languages, coding, design, music) but lack an accessible platform to monetize or barter them.
💡

The SkillSwap Paradigm

  • ✓ Dual Teacher-Student Identity: Every participant is simultaneously a mentor and an apprentice. Zero financial cost required to learn.
  • ✓ Reciprocal Synergy Algorithm: Instantly matches complementary needs (e.g. Alice teaches C# to learn Spanish; Bob teaches Spanish to learn C#).
  • ✓ Integrated Classroom: Native WebRTC video calling, real-time shared notepad, and mutual completion telemetry directly inside the browser.

Design Patterns

CQRS & Pipeline Behaviors in Action

⚡ Segregated Command & Query Pipelines

Commands (Mutations) State Changing

Execute business transactions, validations, entity transitions, and emit domain events.

CreateSwapRequestCommand • AcceptSwapRequestCommand • ConfirmSessionCompletionCommand
Queries (Reads) Read-Only

Optimized read projections using AsNoTracking(), direct DTO mappings, and search filters.

GetRecommendedMatchesQuery • GetSessionCallStatusQuery • GetHomeFeedQuery

🛡️ MediatR Pipeline Interceptors

1
LoggingBehavior<TRequest, TResponse>
Structured telemetry, user audit identity, and execution timestamps.
2
ValidationBehavior<TRequest, TResponse>
FluentValidation pre-handler pipeline; fails fast with formatted HTTP 400.
3
Target Command / Query Handler
Pure domain logic execution returning Result<T> with localized messages.
Key Benefit: Zero cross-cutting boilerplate inside controller actions. Controllers remain ultralight dispatchers.

Matching Formula

The platform calculates bi-directional skill compatibility between the active user \(A\) and any community peer \(B\):

Synergy = (TeachMatch ✕ 0.5) + (LearnMatch ✕ 0.5)
Where TeachMatch = (A.Offered ∩ B.Wanted) ≠ ∅

Enterprise Security

OWASP Security, JWT & External OAuth

🔐

Identity & JWT Lifecycle

  • • JWT Access Tokens: 2-hour lifespan with cryptographically signed HMAC-SHA256 claims.
  • • Refresh Token Rotation: 7-day rolling sliding expiration stored in DB.
  • • Two-Factor Authentication: RFC 6238 TOTP compliant (Google/Microsoft Authenticator).
🌐

Multi-Provider Social Auth

  • • Google OAuth 2.0: `GoogleJsonWebSignature` token validation.
  • • Apple Sign-In: JWT identity token with private relay support.
  • • Facebook Graph Auth: Secure access token inspection.
  • • Auto-Provisioning: Automatic account creation & User role assignment.
🛡️

Platform Hardening

  • • CSRF Protection: `[ValidateAntiForgeryToken]` across all MVC actions.
  • • SQL Injection Immunity: Parameterized LINQ queries via EF Core 8.
  • • XSS Sanitation: Automatic HTML output encoding in Razor engine.
  • • Rate Limiting & CORS: Explicit origin controls for mobile & web.
✅ Zero-Exception External Login Test: Google, Apple, and Facebook sign-in fully verified with automated user generation and cookie synchronization. 100% Pass Rate
